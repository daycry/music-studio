## Alcance y límites

Cada corrida contiene los mismos **19 tests UI con API interceptada y 2 smokes HTTP reales**; las tres repeticiones no son 63 escenarios distintos. Los fixtures UI cierran con 404 las rutas no declaradas. Audio WAV silencioso, VRAM y eventos son sintéticos. API-01/02 usan exclusivamente el server HTTP temporal sin engines y con datos aislados en `.cache/`; no validan el backend de generación/reintento B3. No se accedió a la base de datos del usuario, ni se ejecutaron WSL, Docker, Ollama, inferencia GPU o instalaciones.

La evidencia CPU no demuestra dispatcher y engine-mock integrados, persistencia SQLite, post-proceso FFmpeg Linux, SSE/Range reales, recuperación tras reinicio ni generación musical. No cierra T-04, T-05, T-07, T-15 completa o M1. No se han modificado código de producto, Git, ledger, estados ni criterios desde esta auditoría.

Comando usado en cada corrida, con `scripts/env.ps1` cargado:

```powershell
& scripts/pnpm.ps1 --filter ./apps/web exec playwright '--' test --config=playwright.cpu.config.ts
```
