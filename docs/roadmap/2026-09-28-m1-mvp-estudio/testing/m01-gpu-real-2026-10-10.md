# M-01 - generacion real ACE-Step (2026-10-10)

## Alcance

Se ejecuto la prueba GPU real del engine `engine-acestep` dentro de Docker, con el modelo `ace-step-1.5-turbo`, modo `bf16`, 30 segundos, una salida y descarga explicita del proceso hijo.

Antes de cargar el modelo:

- `wsl -d Ubuntu -e ollama ps`: sin modelos cargados.
- `nvidia-smi`: 1.163 MiB usados de 12.227 MiB.
- La imagen se reconstruyo con `docker compose build engine-acestep` y el contenedor se recreo con `docker compose --profile engines up -d --force-recreate engine-acestep`. La imagen anterior era `m0-t19-preflight`; la ejecucion valida usa el checkout actual.

## Comando

```powershell
docker exec -e STUDIO_ALLOW_UNVERIFIED=1 -e STUDIO_ENGINE_CONTAINER=1 music-studio-engine-acestep-1 uv run pytest tests/test_gpu.py -m gpu -q -s
```
