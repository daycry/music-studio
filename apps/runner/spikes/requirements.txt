# NOTA (2026-09-03): la fuente de verdad de versiones es
# `apps/runner/adapters/ace_step/Dockerfile` (base pytorch/pytorch 2.13.0-cuda12.6
# fijada por digest, transformers 5.16.1, safetensors 0.8.0, ...). Este fichero
# sirve para correr en el host y se mantiene alineado con la imagen a mano.

torch==2.13.0
# Motor de inferencia. Es lo que aporta CUDA, la deteccion de VRAM
# (`_timing.vram_snapshot_mb`, `_timing.gpu_info` -> `torch.cuda`) y el
# offloading por debajo de los 24 GB de confort (D-06/D-29). Instalalo desde el
# indice cu126; la rueda de PyPI viene sin CUDA y dejaria el adapter cayendo al
# mock en silencio, que es justo el fallo que los spikes vigilan.

torchaudio==2.13.0
# Lectura y escritura de audio del pipeline del modelo. Version acoplada a la de
# torch (2.13.x con 2.13.x): un desparejo aqui rompe la carga de extensiones
# nativas con un error que no menciona la causa. No se usa para el resample de
# exportacion a 48 kHz, que va con soxr y es T-19/T-45, no Fase 0.

safetensors==0.8.0
# **La unica puerta de entrada de pesos permitida (D-14).** Formato sin
# ejecucion de codigo al deserializar. Prohibido `torch.load`, `pickle`,
# `joblib`, `dill` o `np.load(allow_pickle=True)` sobre un checkpoint: cargar un
# pickle EJECUTA el codigo que lleve dentro (RCE), y `weights_sha256` verifica
# integridad, NO inocuidad. `contracts.assert_safetensors()` rechaza cualquier
# otra extension antes de abrir el fichero.

numpy==2.1.3
# Dependencia real de torch/torchaudio y del pipeline del modelo. Se fija de
# forma explicita porque el salto a la serie 2.x rompe extensiones compiladas
# contra 1.x: dejarla implicita convierte una actualizacion transitiva en un
# fallo de importacion en la GPU. Los spikes NO la usan: `_timing.summarize()`
# calcula media, mediana y p95 con `statistics` y `math` para que el modo mock no
# dependa de nada.

soundfile==0.12.1
# OPCIONAL, solo para `capability_probe.py` (T-07). El perfil de energia con el
# que la sonda detecta si un parametro de capacidad tuvo efecto se lee con el
# modulo estandar `wave` cuando el artefacto es WAV; si el adapter entrega FLAC o
# MP3 (D-09), la biblioteca estandar no lo decodifica y la sonda intenta un
# import PEREZOSO de soundfile. Sin el, la comparacion se degrada y el informe lo
# declara en vez de fingir la medida. Necesita `libsndfile` en el sistema (en la
# imagen Debian/Ubuntu del contenedor: `apt-get install -y libsndfile1`).
